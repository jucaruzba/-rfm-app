# Final Design Spec — Copy/Paste for Developer

*Sidebar*
- Background: #171717
- Active tab: #2C2C2E
- Sign out: #FF6961 text on transparent red

*Canvas / Pages*
- Background: #FAFAFA (off-white, not pure white)
- Cards/panels: #FFFFFF
- Borders: #E5E5EA (thin, 0.5px)
- Corner radius: 10-14px

*Primary Accent (buttons, links, active states)*
- #5B5FEF (indigo)

*Status Colors*
- Pending: #EF4444 (red)
- In progress: #F59E0B (amber)
- Completed: #10B981 (green)
- Blocked: #6B7280 (gray)
- Priority (high): flame icon + #EF4444 text only, never a full badge

*Text Colors*
- Primary: #1C1C1E
- Secondary: #6E6E73
- Muted: #AEAEB2

*Font*
- SF Pro (fallback: Inter)
- Page titles: 20-22px, semibold
- Body text: 13-14px, regular
- Labels/badges: 11-12px, lowercase

*Icons*
- Outline style, 1.5px stroke
- Size: 14-17px
- Color: gray by default, colored only when meaningful

*Text Casing Rule*
- Titles & buttons: Sentence case ("New task," "Save changes")
- Field labels & badges: lowercase ("description," "pending," "high priority")
- User-typed content: exactly as typed

*Every Page Header*
- Date + bell icon, top-right, same spot, every single page, no exceptions

*Every Popup*
- Plain titles: "New task," "New user" — no jargon, no subtitles
- White background, not dark

*Default Landing Page*
- Opens to Tasks (Dashboard is placeholder until built)
